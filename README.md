# Idea Lab

> 一个轻量、纯静态的个人开源实验仓库，把日常脑洞落地成开箱即用的页面。

## 项目介绍

Idea Lab 是我的个人开源实验仓库，用来存放日常脑洞、实用小工具、知识百科、查询手册等纯静态 HTML 页面。

所有项目轻量化、无框架、开箱即用，支持 GitHub Pages 直接在线访问。

适合场景：

- 各类轻量在线工具
- 技术 / 生活百科知识库
- 个人灵感落地小项目
- 随手实现的极简 Demo

## 仓库特点

- **纯静态页面**：HTML / CSS / JS，零依赖，可直接双击本地打开
- **轻量化**：简洁实现，不冗余，不堆砌复杂框架
- **可公开查阅**：所有内容开源可浏览、可参考、可复用
- **持续更新**：持续新增工具、百科文档、创意 Demo

## 项目清单

| 项目 | 简介 |
| --- | --- |
| [囚徒健身 · 六艺十式打卡](ConvictConditioning/main.html) | 基于《囚徒健身》六艺十式体系的训练日志，包含动作要点、三级训练目标、每日打卡与长期统计，配实拍图例，数据保存在本机 |
| [工位伴侣 · 久坐 / 喝水提醒](SitReminder/main.html) | 面向坐班族的健康伴侣：久坐与补水两类提醒参数各自独立、共用一条统一提醒引擎，带活动倒计时、30 秒微运动、饮水记录、随机拉伸建议与今日统计，数据保存在本机 |

### 囚徒健身 · 六艺十式打卡

- 覆盖六艺各十式：俯卧撑、深蹲、引体向上、举腿、桥、倒立撑，共 60 个动作
- 每一式配有原创整理的要点、常见错误与分批补齐的实拍动作图例
- 卡片内按原书展示初级 / 中级 / 升级三档训练目标（终极式为精英标准，如 1×10、2×25、3×50）
- 卡片内用 `‹ ›` 切换相邻式，可设定当前阶梯、一键打卡
- 统计连续天数、累计训练天、总打卡次数，展示近一周与最近 30 天历史
- 记录仅保存在浏览器 localStorage，支持导出 / 导入 JSON 备份，不上传任何服务器
- 图例与二维码由 Service Worker 缓存，正常使用不会重复请求 OSS

### 工位伴侣 · 久坐与喝水提醒

**两类提醒，参数各自独立**

- 久坐站立：独立开关 + 久坐间隔（快捷 30 / 45 / 60 / 90 分钟）+ 活动时长，坐满自动进入活动倒计时
- 补水：独立开关 + 提醒间隔 30 / 45 / 60 / 90 分钟（默认 60）+ 每日目标 1500 / 1700 / 2000 ml（默认 1700）
- 关闭某一类不影响另一类：关久坐后计时仍按间隔滚动但不弹起身提醒，关补水后不再规划下一次
- 饮水记录：+150 / +200 / +300 ml 快捷记账、多步撤销（默认最多 30 步）、进度条与达标提示，按日期自动归零

**一条统一的提醒引擎，尽可能把人从屏幕里拉出来**

不论触发的是哪一类，到点都走完全相同的链路，可在「提醒设置」中逐项开关：

| 通道 | 行为 |
| --- | --- |
| 提示音 | 双音播放；可选循环 1 分钟或仅播放 3 次，点按横幅即停 |
| 语音播报 | 用系统 TTS 直接念出提醒内容 |
| 长振动 | Android 每 1.2 秒震一次，持续约 90 秒 |
| 桌面通知 | 常驻通知，点按回到页面（Android 经 SW 显示） |
| 标签闪烁 | 标题与 favicon 交替闪烁 |
| 页面横幅 | 顶部横幅，补水提醒带「喝了 200 ml」一键记录 |
| 全屏遮罩 | 整页拦截，带倒计时与一键回应；起身为绿系、补水为青系 |

- 不使用独立弹窗：浏览器对后台自动开窗限制多、易被拦截，提醒统一落在页面内与系统通知上
- 通知图标固定使用工位伴侣自己的时钟标记（运行时 canvas 生成 data URI，不引用额外图片文件），不会串用同源其它项目的图标
- **30 秒微运动**：起身遮罩上随机给一个动作（靠墙站立 / 自重深蹲 / 窗前远眺 / 扩胸 / 肩颈绕环 / 提踵走动），第一次点主按钮开始倒计时，做完再点一次确认；随时可提前结束，不强制锁定
- **提醒节流**：上一次提醒结束后 3 分钟内不再开新的；补水提醒若在 5 分钟内到期，就顺延一整轮并写进本次遮罩（「这次一并提醒：小口喝 200 ml 水」），避免两类提醒轮番轰炸
- 未响应升级：每 45 秒再补一次语音、震动与标题闪烁（循环提示音模式下还会补响）；5 分钟后自动收起遮罩，转为稍后再提
- 提醒互斥排队：同一时刻只允许一个提醒在场；久坐到点前 3 分钟内，补水会让位给起身提醒
- 补水依据《中国居民膳食指南（2022）》：温和气候、轻体力活动下成年男性 1700 ml、女性 1500 ml，主动少量多次，每次约 200 ml；高温或出汗多时上调
- 页面保持前台时申请屏幕常亮，降低锁屏漏提醒的概率
- 提示音关闭、无通知权限或 iOS 无震动时，自动降级为遮罩 + 标题闪烁 + 横幅，链路不会断
- 跨端适配：PC 浏览器支持通知与语音；Android 支持振动与经 Service Worker 显示的常驻通知（需 https）；iOS 无振动与网页通知，由遮罩、声音、语音与标题闪烁承担提醒
- 移动端细节：刘海屏与手势条安全区适配、主要操作按钮保持约 44px 触控高度、输入框字号防 iOS 聚焦缩放，全屏遮罩期间正确锁定页面滚动
- 手机振动需页面保持前台亮屏，标签页切后台仍按真实时间计时
- 每次活动随机点亮 3 条拉伸建议（接水走动、靠墙站立、深蹲等）
- 「起身做点什么」底部提供囚徒健身入口，新标签页打开同仓库的在线训练页
- 统计今日起身次数、久坐时长、活动时长与饮水毫升数，按日期自动归零，数据保存在本机
- **数据管理**：页面底部可单独清空今日久坐（起身 / 久坐 / 活动）、今日饮水，或清空全部数据（含二维码缓存）；清空为两次点击确认，避免误触
- **设为浏览器首页**：页面提供在线部署地址复制与对应浏览器的设置路径（Chrome / Edge / Firefox / Safari），受浏览器安全限制需手动添加一次
- 关闭页面即停止计时，刷新后 10 分钟内的进度可恢复

**科学依据**

- [中国营养学会《中国居民膳食指南（2022）》](https://www.cnsoc.org/)：足量饮水、少量多次，温和气候与轻体力活动下成年男性每日饮水 1700 ml、女性 1500 ml
- [EFSA《Dietary Reference Values for Water》(2010)](https://doi.org/10.2903/j.efsa.2010.1459)：成年男性 2.5 L、女性 2.0 L 总摄水量（含食物水分，约 80% 来自饮品）
- [Wittbrodt & Millard-Stafford, 2018](https://doi.org/10.1249/MSS.0000000000001682)：脱水超过体重 2% 时，注意力与运动协调表现下降

## 本地使用

无需安装任何环境，克隆仓库后用浏览器打开任意 `.html` 文件即可：

```bash
git clone git@github.com:CoderShang/idea-lab.git
```

也可以直接下载单个 HTML 文件，双击打开使用。

## 技术说明

- 原生 HTML / CSS / JavaScript，无第三方库、无构建步骤
- **单文件架构**：每个项目的 HTML、CSS、JS 全部内联在同一个 `.html` 里，无外链样式、外链脚本与外部字体；图标与界面图形由内联 SVG / canvas 生成，字体使用系统字体
- **图片资源**：囚徒健身的实拍图例托管在阿里云 OSS（仓库内不存图片），按 `img_{艺}_{式}_{序号}.jpg|png|webp` 命名，页面逐个格式探测、存在才展示；工位伴侣只有打赏与联系方式两张二维码来自 OSS
- **Service Worker**：`SitReminder/sw.js` 与 `ConvictConditioning/sw.js` 是仅有的外部文件，浏览器规范要求它必须注册同源的真实文件（`blob:` / `data:` 均被拒绝），无法内联；两者都延后到首屏加载完成后的空闲期才注册，不阻塞渲染、不与首屏资源抢请求。前者负责 Android / 桌面的通知通道，后者只做图片缓存
- **图片缓存**：两个页面各用 Service Worker 对 OSS 图片做 cache-first 缓存（`CacheStorage` 分区 `oss-img-sr-v1` / `oss-img-cc-v1`），命中后不再产生 OSS 请求；囚徒健身还会把「哪些图例存在」的探测结果记在 `localStorage`（`cc_imgmap_v1`，7 天有效），避免反复探测不存在的图片
- **清空与换图**：页面里的「清空全部数据」会一并删掉本站图片缓存与探测清单，下次打开重新取图，且只删自己的前缀、两个页面互不影响；替换同名图片时把 `main.html` 与 `sw.js` 里的 `v1` 一起改成 `v2`，新增图例时把 `cc_imgmap_v1` 改成 `cc_imgmap_v2`
- **本地打开的限制**：双击 `.html` 以 `file://` 打开时 Service Worker 不注册，图片缓存不生效，页面功能不受影响；需要缓存请使用在线地址
- 数据存储：localStorage，同一浏览器、同一设备有效
- 清除浏览器数据会一并清空记录与图片缓存；囚徒健身页面内提供导出 / 导入 JSON 备份，建议定期备份；工位伴侣的清空操作不可恢复
